# Empaquetado
El taller ZIP entregado al usuario contiene `tools/build_atlas.py` que empaqueta solo PNGs RGBA 160×160 de `approved/` y produce atlas+JSON. Los 160px son provisionales hasta validar con el motor.

**Importante:** todavía NO existe atlas de producción aprobado. El JPG de referencia y los PNGs binarios requieren subida explícita; este repositorio solo contiene por ahora las reglas y el manifiesto. No editar ni sustituir el atlas actual del juego.
